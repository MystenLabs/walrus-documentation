### Walrus Sites v2.12.2

October 21, 2026 | [GitHub](https://github.com/MystenLabs/walrus-sites/releases/tag/mainnet-v2.12.2)

This release moves the portal Docker images to the `oven/bun:1.4.3` base image on Debian 13. The
previous base image reached end of life, which broke `apt` during the server-portal image build in
v2.12.1. If you build or run your own portal, the image now builds again. The site-builder is
unchanged from v2.12.1, and there are no Move contract changes.

`--dry-run` cost estimation still relies on the Sui JSON-RPC `dev_inspect` API, which public Sui
fullnodes no longer serve. Regular `deploy`, `publish`, and `update` commands work as before.

#### Changes

- [server-portal: Move Docker images to `oven/bun:1.4.3` (Debian 13) so `apt` works again in the image build](https://github.com/MystenLabs/walrus-sites/pull/735)
- [Bump version to 2.12.2](https://github.com/MystenLabs/walrus-sites/pull/736)

### Walrus Sites v2.12.1

October 21, 2026 | [GitHub](https://github.com/MystenLabs/walrus-sites/releases/tag/mainnet-v2.12.1)

This release updates the site-builder dependencies. It now builds against Walrus `testnet-v1.58.1`
and Sui `testnet-v1.81.0`, up from `testnet-v1.51.2` and `testnet-v1.74.0`, and uses the Rust 1.96
toolchain. The portal and the Move contracts are unchanged.

One known limitation remains. `--dry-run` cost estimation still relies on the Sui JSON-RPC
`dev_inspect` API, which public Sui fullnodes no longer serve, so cost estimates might not work
against those nodes. Regular `deploy`, `publish`, and `update` commands are unaffected. A gRPC-based
estimate is planned for a follow-up release.

#### Changes

- [site-builder: Bump Sui to `testnet-v1.81.0`, Walrus to `testnet-v1.58.1`, Rust toolchain to 1.96](https://github.com/MystenLabs/walrus-sites/pull/733)
- [site-builder: Initialize typed-store DB metrics once in the integration-test harness to fix a startup race](https://github.com/MystenLabs/walrus-sites/pull/733)
- [Bump version to 2.12.1](https://github.com/MystenLabs/walrus-sites/pull/734)

### Walrus Sites v2.12.0

### Walrus Sites v2.10.0

June 4, 2026 | [GitHub](https://github.com/MystenLabs/walrus-sites/releases/tag/mainnet-v2.10.0)

The portal now bounds each aggregator fetch attempt at 10 seconds and fails over to the next
aggregator URL. It sizes Bun's `idleTimeout` from the full retry chain. A slow aggregator no longer
drops the inbound connection mid-request and causes a generic upstream proxy error. Instead, the
portal returns its own `aggregatorFail()` page.

Portal operators can tune this behavior with `AGGREGATOR_REQUEST_TIMEOUT_MS` (default `10000`) and
`PORTAL_IDLE_TIMEOUT_MAX_S` (default `100`). The portal sanitizes and logs the resolved values at
startup. The site-builder updates Sui to `testnet-v1.73.0` and Walrus to `testnet-v1.50.0`. This
release has no Move contract changes.

#### Changes

- [portal: Size Bun `idleTimeout` from aggregator retry budget; add per-attempt fetch timeout and sanitize-and-log resolved config at startup](https://github.com/MystenLabs/walrus-sites/pull/714)
- [site-builder: Bump Sui to `testnet-v1.73.0`, Walrus to `testnet-v1.50.0`](https://github.com/MystenLabs/walrus-sites/pull/718)

This patch release fixes how the portal handles SuiNS lookups. When a lookup returns `notExists`,

April 23, 2026 | [GitHub](https://github.com/MystenLabs/walrus-sites/releases/tag/mainnet-v2.9.0)

### Walrus Sites v2.8.0

April 2, 2026 | [GitHub](https://github.com/MystenLabs/walrus-sites/releases/tag/mainnet-v2.8.0)

This release adds server-side redirects. You define redirect rules with glob pattern matching in
`ws-resources.json`. The rules are stored as dynamic fields on the on-chain `Site` object. The
portal evaluates redirects before fetching resources and serves a 3xx response. To use redirects,
update `package_id` in `sites-config.yaml` to the latest upgraded `walrus_site` package ID. You can
also remove the field so MVR resolves it automatically.

The portal config field `site_package` is renamed to `original_package_id`. The portal now uses
Mysten SDK v2. The server portal's aggregator histogram no longer includes the `blobOrPatchId` and
`path` labels.

### Walrus Sites v2.7.0

March 12, 2026 | [GitHub](https://github.com/MystenLabs/walrus-sites/releases/tag/mainnet-v2.7.0)

This release improves the reliability of the site builder. Large sites, those with 500 or more
routes or resources, no longer fail with `InsufficientGas` errors. These failures came from
programmable transaction block (PTB) byte-size overflow, which the site builder now prevents.

Site deployment also handles transient Sui object version conflicts better. When a conflict occurs,
the site builder automatically retries the operation with exponential backoff instead of failing.

#### Changes

- [site-builder: Prevent PTB byte-size overflow for large sites](https://github.com/MystenLabs/walrus-sites/pull/674)
- [site-builder: Retry on Sui object version conflicts](https://github.com/MystenLabs/walrus-sites/pull/660)

### Walrus Sites v2.6.0

February 26, 2026 | [GitHub](https://github.com/MystenLabs/walrus-sites/releases/tag/mainnet-v2.6.0)

The portal now reads its configuration from a YAML file: `portal-config.yaml` by default, or the
path you set in `PORTAL_CONFIG`. All existing environment variables still work as overrides on top
of the YAML. See `portal-config.*.example.yaml` for the schema.

This release also includes the v2.5.0 priority-based executor. It tries RPC and Aggregator URLs in
priority order, with per-URL retries, using the format `URL|RETRIES|METRIC`. `AGGREGATOR_URL`
becomes `AGGREGATOR_URL_LIST`, and `RPC_URL_LIST` and `PREMIUM_RPC_URL_LIST` use the new format. The
portal still accepts the old format but prints a deprecation warning. The site builder now errors
gracefully on invalid glob patterns in `ws-resources.json` and fixes a lowercasing issue with header
mappings.

### Walrus Sites v2.0.0

November 17, 2025 | [GitHub](https://github.com/MystenLabs/walrus-sites/releases/tag/mainnet-v2.0.0)

This release removes legacy blob publishing and the `experimental-quilts` feature flag. The portal
still serves both Quilt and blob-based sites. Updating a site re-uploads all site data. If that is a
concern, test on testnet first, republish to a new site and point SuiNS to it, or stay on
mainnet-v1.3.1.

The `--check-extend`, `--watch`, `--parallel-stores`, and `--max-concurrent` flags are removed.
`update-resource` is renamed to `update-resources`, which accepts multiple `local_path:site_path`
pairs. A default 512 MiB limit per Quilt, which also caps individual file size, applies; override it
with `--max-quilt-size`. Patch identifiers now use the resource's site path. `StoredQuiltPatch`
gains a `range` field for Walrus CLI v1.35 compatibility.

#### Changes

- [Added comprehensive test coverage for `max-quilt-size` limit enforcement.](https://github.com/MystenLabs/walrus-sites/pull/591)
- [Updated Sui and Walrus dependencies.](https://github.com/MystenLabs/walrus-sites/pull/598)

Header and ignore-file matching in `ws-resources.json` now uses glob patterns, such as `*.md` and
`docs/**`, instead of regular expressions. Regex support was never intentional, so if your
configuration relies on advanced regex, update it to glob style. This release also fixes how
`--list-directory` handles ignore files.

Quilt support under the `quilts-experimental` feature expands. The site-builder adds an
`UpdateQuilts` command that deletes and re-creates all resources, and it shows quilt patch IDs in
publish, update, and sitemap output. The deploy action now supports wallet exported keys and fixes
how it uses inputs. Range header building in common-lib is also fixed.

### Walrus Sites v1.1.0

September 8, 2025 | [GitHub](https://github.com/MystenLabs/walrus-sites/releases/tag/mainnet-v1.1.0)

This release adds an experimental way to publish sites as quilts instead of blobs. `site-builder
publish-quilts --epochs=<EPOCHS> <YOUR-BUILD-DIR>` bundles multiple resources as quilt patches on
Walrus, which significantly reduces publishing cost. The command is available only when you build
`site-builder` from source with `cargo build --features quilts-experimental`. The portal now derives
`quiltpatchid` and retrieves quilt-based resources.

`site-builder` now updates the site name when it changes in `ws-resources.json`. An explicit
`walrus_package` argument now overrides the config value, and `site-builder` catches transaction
failures earlier. The portal and server portal no longer include Sentry or Vercel web analytics.
