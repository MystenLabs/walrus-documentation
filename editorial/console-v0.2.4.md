**November 9, 2026**

This release makes uploading easier from anywhere in Walrus Console. The Assets home has an upload
button, a drop zone, and page-wide drag hover, and a new destination step lets you choose an
existing folder or create one. Each folder also has its own upload button and drop zone.

Folder handling is more reliable: deleting a folder no longer leaves it stuck in a deleting state,
and the last folder stays listed after you delete the others. Walrus Memory keeps the open
namespace in the URL and starts a fresh sign-in after a disconnect. The release also includes
security strengthening.
