**Mainnet** | March 19, 2026

Walrus 1.44.2 is a Mainnet release that contains a single storage node fix. It resolves an issue
that caused storage nodes to crash because of outdated epoch state.

If you operate a Mainnet storage node, this release addresses that crash. The release lists no other
changes to storage nodes, clients, or other components.
