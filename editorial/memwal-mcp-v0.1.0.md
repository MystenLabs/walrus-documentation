**November 4, 2026**

This release adds the `memwal-mcp status` and `whoami` CLI subcommands. You can use them to check
how your Walrus Memory MCP setup is configured, including the current account, delegate, label,
relayer, namespace, credentials file, and auto-save configuration.

Both subcommands run without interactive prompts. You can check your active configuration from the
command line without stepping through the setup flow.
