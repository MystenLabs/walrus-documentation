**November 3, 2026**

Walrus Console is generally available. Visiting the app takes you straight to the sign-in page,
which now fits laptop screens. New welcome screens and a three-step tour introduce the console
after you sign in, and Walrus Memory offers to use an existing account on its first screen.

Connecting an MCP client is simpler: you can download the Claude Desktop MCPB bundle with an
install video, or use the Add to Cursor link, both pinned to `walrus-console-mcp` 0.1.0. The
release also includes security strengthening.
