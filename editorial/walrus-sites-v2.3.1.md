**January 29, 2026**

This hotfix release disables child process uploads in `site-builder`. That change fixes JSON parsing
errors that occur when `site-builder` works with the Walrus CLI.

This release requires Walrus CLI v1.37.0 or later. Check your installed Walrus CLI version and
upgrade it, if needed, before you use this version of `site-builder`.
